# Viral Shorts Hook & Retention Architect

> **Compatibility:** Claude Code, Cursor, GitHub Copilot, Codex, Windsurf, Gemini Antigravity, and all agents supporting the `SKILL.md` standard.

---

## ⚡ What This Skill Does

This skill turns your AI coding or writing agent into a **world-class Short-Form Retention Engineer**. 

Whenever you ask your agent to write, polish, or format a YouTube Short, TikTok, or Instagram Reel, it automatically applies:
- 🎣 **Zero-Fluff Cold Opens:** Eliminates greetings and preamble; hooks viewers in under 500ms.
- ⏱️ **The 3.5-Second Pattern Interrupt:** Enforces visual drift, color pop, and camera motion inversion formulas to kill audience drop-off.
- 🔁 **Seamless Infinite End-Loops:** Crafts ending sentences that grammatically bridge back into the opening hook, multiplying replay retention (>100% completion rates).
- 📊 **Optimal Pacing Calculations:** Enforces the golden 145–165 WPM cadence and 7–11 second scene limits.

## 📦 How to Install

### 1. Claude Code
Copy the `SKILL.md` file into your Claude Code custom skills directory:
```bash
# In your project root
mkdir -p .claude/skills/hook-retention-engineer
cp SKILL.md .claude/skills/hook-retention-engineer/
```

### 2. Cursor
Place `SKILL.md` in your `.cursorrules` or `.cursor/rules/`:
```bash
cp SKILL.md .cursor/rules/hook-retention-engineer.md
```

### 3. Antigravity / Gemini CLI / Codex
Place `SKILL.md` into your `.agents/skills/hook-retention-engineer/`:
```bash
mkdir -p .agents/skills/hook-retention-engineer
cp SKILL.md .agents/skills/hook-retention-engineer/
```

## 🚀 How to Use

Simply prompt your agent naturally:
- *"Write a 50-second YouTube Short script about why airline pilots can't eat the same food."*
- *"Audit this video script for audience retention and rewrite the hook to prevent swipe-aways."*
- *"Add camera direction and pattern interrupts to this 6-scene script."*

Your agent will automatically read `SKILL.md` and deliver an algorithm-optimized script ready for production!
