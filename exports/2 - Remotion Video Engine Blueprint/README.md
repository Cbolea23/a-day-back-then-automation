# Remotion Video Engine Blueprint

> **Compatibility:** Claude Code, Cursor, GitHub Copilot, Codex, Windsurf, Gemini Antigravity, and all agents supporting the `SKILL.md` standard.

---

## ⚡ What This Skill Does

This skill gives your AI coding assistant the complete architectural knowledge to **build, animate, and render programmatic React videos using Remotion**.

Whenever you prompt your agent to create video components, synchronize audio tracks, animate subtitles, or set up render scripts, it automatically:
- 🎥 **Applies Dynamic Camera Interpolation:** Generates smooth `interpolate()` zoom and pan drift formulas that keep static background assets moving.
- 🗣️ **Implements Frame-Accurate Speech Sync:** Normalizes audio length to 30 FPS frames with zero clipping, chopping, or sound cutting.
- 🔤 **Builds Kinetic Word-by-Word Typography:** Generates 3-word chunked subtitle animations with active syllable scale pops.
- ⚙️ **Configures High-Performance CLI Rendering:** Provides optimized headless Remotion render commands with scale drafts and snapshot stills.
