## Rules

- Check this file before starting any asset — IN PRODUCTION is a lock, not a suggestion.
- READY must include the exact location (drive folder or repo path) of the deliverable.
- Announced counts must match delivered files exactly.
- The owner is the only one who can mark an item CANCELLED.
