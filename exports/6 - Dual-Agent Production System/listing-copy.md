## Description

Two AI agents are twice the output — and twice the chaos, unless they run under a contract. The Dual-Agent Production System is the complete operating system for a human owner running two agents as one team: a remote "Factory" agent that generates and renders in bulk, and a local "Builder" agent that works inside your apps and holds your platform tokens.

You get the role-assignment rule (work follows where accounts and files physically live), the two-channel law (code through git, media through a shared drive — with the measured cost of getting it wrong), the live Discord Operations Bridge (executable scripts for real-time machine-to-machine event dispatches and autonomous listener daemons), the handover checklist format that acts as the single source of truth, the context-brief template that onboards a cold agent instance in one read, standing-permission fences that keep agents fast but leashed, and review gates that guarantee nothing publishes without your explicit approval.

Built and proven in a live operation running a content channel, a game project, and a skills storefront with two agents daily.

## FAQ

- **Does this require specific agent products?** No. The system is vendor-neutral — it is built on git, a shared drive folder, written briefs, and zero-dependency Node.js Discord scripts, so it works with any two agents that can read and run files.
- **I only have one agent. Is this useful?** The brief and checklist discipline still pays off across sessions (your agent's future instances are effectively new teammates), but the full value shows with two.
- **Does it include content or creative skills?** No — this is the coordination layer only. Creative pipelines (hooks, voice, rendering) are separate skills; this system is how you run them with two agents safely.
- **Can the agents publish on their own under this system?** Only if you write that into your fences. The default gates require your explicit per-item approval for anything public.
