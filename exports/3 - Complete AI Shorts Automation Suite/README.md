# Complete AI Shorts & TikTok Automation Suite

> **Compatibility:** Claude Code, Cursor, GitHub Copilot, Codex, Windsurf, Gemini Antigravity, and all agents supporting the `SKILL.md` standard.

---

## ⚡ What This Suite Does

This master suite turns your AI coding assistant into a full **Autonomous Short-Form Video Production Studio**.

It bundles four specialized production disciplines into one unified agent skill:
1. **Viral Hook & Retention Architect:** Cold opens, 3.5s pattern interrupts, and seamless loops.
2. **Video Scriptwriting Ideator:** 145–165 WPM pacing, structured scene beats, and curiosity gaps.
3. **Kinetic Caption Processor:** Mobile-safe 3-word subtitle chunks with active syllable pops.
4. **Remotion Video Engine:** React composition architecture, dynamic camera drift math, and headless rendering.

## 📦 How to Install

### 1. Claude Code
```bash
mkdir -p .claude/skills/ai-shorts-automation-suite
cp SKILL.md .claude/skills/ai-shorts-automation-suite/
```

### 2. Cursor
```bash
cp SKILL.md .cursor/rules/ai-shorts-automation-suite.md
```

### 3. Antigravity / Gemini CLI / Codex
```bash

cp SKILL.md .agents/skills/ai-shorts-automation-suite/
```
